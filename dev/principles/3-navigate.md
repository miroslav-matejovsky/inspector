# Navigate

The primary purpose of an Inspector is to make relationships navigable.

Complex systems are understood through connections rather than isolated objects. An Inspector should allow users to move naturally between related concepts, revealing the context, dependencies and relationships that shape system behaviour.

Navigation is not search. The goal is not merely to locate information, but to explore and understand how parts of the system connect to one another.

An Inspector should help answer questions such as:

- How is this connected?
- What does this depend on?
- What contributed to this?
- What is related to this?
- Where should I look next?

A good Inspector enables users to start from any point in the system and progressively build understanding by traversing the model and its relationships.

If users can see information but cannot follow its connections, navigation has failed.

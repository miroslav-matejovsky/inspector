# Repository assessments

Evidence-backed reviews of the first-party repository, its execution workflows,
architecture, test coverage, and implementation priorities.

Each report is stored in its own folder within the dev/assessments directory.
Each folder contains a README.md and records the source revision,
assessment limits, findings, and acceptance criteria for recommended work.
Other files in the folder support the assessment by providing detailed findings, evidence, and any supplementary materials.
Files do not have strict structure and may vary depending on the nature of the assessment.
